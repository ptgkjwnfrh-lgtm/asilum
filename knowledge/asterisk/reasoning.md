# ASTERISK — honesty & explanation contract

lib/ai/contract.js defines three states every intelligent surface must use:
real / mockMarked / notImplemented. Nothing may present simulated output as
real (constitution law). Coming-soon buttons use class `soon` (red).

Explanations are derived from actual arithmetic: match reasons name the
tags/bridges that scored, search returns confidenceScore + matchReason +
matchedTags. If a number can't be traced to a stored signal, don't show it.

Future generative layer (if ever): must be env-gated, surface-labeled, and
constitution-amended first.
