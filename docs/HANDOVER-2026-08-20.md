## Traps learned 20 August

20. **A Vercel env var marked "Sensitive" is write-only FOREVER** — even
    Edit shows a blank field. Don't hunt for the old value; mint a new one
    (openssl → pbcopy, never through a transcript), save it in the
    owner's password manager THIS time, redeploy. Env changes apply only
    to NEW deployments — redeploy or the old value serves.
21. **AT ghost-click** (found by ear during claim 12): assistive-tech
    activation can double-fire a click at the trigger's screen position;
    the duplicate lands on whatever now occupies that point — an overlay —
    and dismisses the thing that just opened. Guard EVERY overlay
    click-away with target-is-overlay + a birth window
    (`useOverlayDismiss`). No static test sees this class; only a person
    at a screen reader does — which is why claim 12 existed.
22. **The user's Chrome ≠ the extension's tab group.** Script-created tabs
    land in the MCP group without fronting a window — the owner can be
    staring at a desktop while "the page is open". `open_application`
    fronts Chrome; `Control_Chrome`'s `switch_to_tab` fronts a specific
    tab; only then is a staged page actually ON SCREEN. And dashboard SPAs
    (Vercel) may never render rows into the a11y tree — their own
    authenticated API from the page context (`fetch('/api/…')`) is the
    reliable read.
23. **GitHub's web editor bypasses the token's `workflow`-scope wall** —
    the owner committing via browser activates a workflow the CLI cannot
    touch. The reverse also binds: agents STILL cannot edit
    `.github/workflows/*` (stale header comment in deploy-drift.yml
    stands as evidence).
24. **The first run of a drift-watching workflow judges an in-flight
    deploy** — expect red-that-means-catching-up on activation day; the
    nine-times lesson applies to the watcher's own verdicts.
25. **A pipe destroys the merge ritual.** `gh pr checks --watch
    --fail-fast | tail -4 && gh pr merge …` returns TAIL's exit code —
    the shell saw 0 on a FAILED check and merged #303 red (the #262
    lesson, reproduced at one remove). Nothing may stand between the
    check command and its `&&`; when output must be trimmed, gate a
    sentinel instead (`… --fail-fast >/dev/null && echo GREEN`, merge in
    a separate command after seeing it). Fixed forward the same hour:
    #304, CI green on main again.
26. **Every `schema-vN` file must record itself** —
    `INSERT INTO app_schema_migrations (version, name) … ON CONFLICT DO
    NOTHING` at the tail (v33 pattern), and the rollback note deletes the
    row. CI's migration hole-check fails the whole build on a committed
    file with no ledger row, and it is right to. When a migration is
    applied to prod via MCP, the ledger row goes with it.
27. **Stripe physics, learned against the live API (both pinned as
    tests):** (a) a STANDALONE charge under 50¢ USD is refused
    (`amount_too_small`) — the ruled 31¢ floor holds only where the fee
    rides a larger charge; fee-only charges floor at
    `STRIPE_MINIMUM_CHARGE_CENTS`; (b) a PaymentIntent carrying
    `setup_future_usage` REFUSES `off_session` confirmation — ask Stripe
    to save the card only while no card is saved.
28. **Supabase reserves schema `vault`** (its own Vault extension owns
    it — `permission denied` on CREATE TABLE even though CREATE SCHEMA
    IF NOT EXISTS "succeeds" as a no-op). Name your schema something
    else (`buyer_vault`).
29. **Pane driving:** `form_input` on a React checkbox sets the DOM but
    not React state — drive it with `el.click()` from javascript_tool;
    and a 0x0 viewport (hidden pane) recovers with an explicit
    `resize_window` width/height, not `tabs_select`.
