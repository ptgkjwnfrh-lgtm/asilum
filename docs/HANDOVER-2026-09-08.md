## 6. Traps learned this window (119–141)

* **119** — the catalog grid was **column-major**: "after the last examined
  index" found a 7-card tail under index 64 and declined every re-chunk.
  Found by walking React fibers (`memoizedState` refs) in the page — that
  reads `useRef` values without a rebuild.
* **120** — `tests/shared-constants.test.js` names every duplicated constant:
  import, never copy.
* **121–123** — the rest of the #433 round, recorded in its PR body and the
  6 Sep memory block; the ones that recur: the lane must walk the *filtered* pool; whitelists
  (`SERVE_ZONES`, `PUBLIC_ZONES`, `PUBLIC_BRIDGES`, events) each needed
  `catalog` separately; a cold slate equals the listing head, so ties must
  break on an id hash, never on pool order (chunk 2 repeated chunk 1).
* **124** — a verifier's "in-place replacement" still *removed* planned cards
  when no fresh item stood in (65 gone for 22 arrivals): replace-or-keep.
* **125** — geometry must protect one full screen below the fold; a
  half-visible card is never "examined".
* **126** — a Bloom filter sized for the rendered ceiling saturates when a
  test walks the whole catalog — size for the catalog, not the viewport.
* **127** — CSS multicol "in place" is count-stable, not geometry-stable:
  measure rects, not ids.
* **128** — a removal under index-bucketed columns re-buckets everything
  after it (59/59 moved): a column must be card state.
* **129** — FNV positions mod a power of two use only the low bits
  (sequential ids collided 35×): add a finalizer.
* **130** — a Bloom false positive is permanent unless something ignores the
  filter: the dry-pool fill rotates.
* **131** — a lane that excludes the seen ring dies forever for a reader who
  saw the whole pool: two passes.
* **132** — "bounded by cards" evicted the *first load* at the first re-chunk:
  pin it.
* **133** — a rotating pointer that records where the *walk* stopped, not
  where it last *took*, returns to its own start when the walk wraps unfilled.
* **134** — an awaited auth chain can cross a task boundary the unloading
  document does not survive; `sendBeacon` cannot carry a bearer — cache the
  headers, issue the beacon synchronously.
* **135** — a flat seen penalty over a ring that holds the whole pool is the
  unpenalised order forever (the same first page every visit).
* **136** — grading that penalty above 0.5 let strong seen items outrank weak
  unseen ones and broke the reach-all law (911/915).
* **137** — a rotating fill's resume position is meaningless in an order that
  re-permutes every chunk: walk a stationary order.
* **138** — a reload's own beacon flush ran under the settle rule and dropped
  the serve it then wiped: the final flush is unconditional.
* **139** — extra gradient layers in a multi-layer `background` shorthand
  inherit the next `background-size` entry (the 140px grid cell) and **tile
  into a checkerboard**; a colour wash is its own layer.
* **140** — rounded-rect distance on a straight side is `r − q`, not `−q`
  (the bezel mask covered a third of the pane until fixed). Debug an SVG
  filter by pointing its last primitive at each intermediate result in turn.
* **141** — `requestAnimationFrame` never fires in a hidden Chrome tab: a
  rAF-based benchmark hangs CDP for 45 s. Front the tab first (osascript:
  set the window's active tab index, then its index to 1). Same family as
  trap 68.
