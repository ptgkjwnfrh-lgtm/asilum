## Rituals (unchanged unless noted)

- **Build/test:** `export PATH="$HOME/.local/node-v20.18.1-darwin-arm64/bin:$PATH"` then `npm run build` / `npm test`. Never export `DATABASE_URL` globally for tests (flips the mem suite onto live Postgres — see the DB-role lessons). Postgres suite: `TEST_DATABASE_URL="$DATABASE_URL"` + `DATABASE_SSL_CA`.
- **Preview:** launch config `asilum-stress-mem` (`:3457`, mem mode, no prod writes). `next start` serves the BUILT app — rebuild + restart to see source edits; stale tabs kill buttons, refresh.
- **Stacked merges (A3):** retarget each child to main (`gh api -X PATCH .../pulls/N -f base=main`) BEFORE `gh pr merge N --merge --delete-branch=false`, then `git merge-base --is-ancestor <head> origin/main`. Never trust the MERGED label. Branches are retained on purpose.
- **Auth:** durable gh token (`~/.config/gh/hosts.yml` + credential helper). No device-flow ritual. `gh pr edit` (GraphQL) may lack scopes — use the REST PATCH above.
- **Workflows:** budget for fleet death — usage limits killed agents twice this round. Findings live in the run's `journal.jsonl`; verification-first beats discovery-first when resuming.
- **Design law:** new text-action classes join the ONE grouped teal rule at the end of `globals.css` (never restate the shadow). Red hovers must swap the whole signal (`--glow-r` shadows), never red text in a teal blur. Sizes a designer would tune ride `--ed-*` tokens with a `lib/uilab.js` registry row — and a registry row must never outlive its effect.
