## Traps learned in the evening round

These are additional to the twelve below, which stand.

13. **Gating a route turns every unchecked `r.json()` on its callers into a
    rendered lie.** `/api/stats` was gated on 16 August; `/cover` read it without
    `r.ok`, so a truthy `401 {error}` body became the data and the masthead
    printed `undefined` four times. **When you gate a route, grep its callers.**
14. **"Change a value, get an identical PNG" is what a NOT-RENDERED element looks
    like — and also what a DELETED one looks like.** Satori silently paints
    neither an SVG data-URI background tile nor a `radial-gradient`; use
    primitives. But when the card's frames vanished I blamed Satori for dropping
    `border`, and it was my own patch, which had replaced a span up to the next
    JSX marker. **Check the file before blaming the renderer.**
15. **`element.focus()` from script does not match `:focus-visible`.** A
    focus-ring audit written that way reports EVERY control as unstyled. Drive a
    real `Tab`. (Trap 3 below is the sibling of this one and both are real.)
16. **"The tooling isn't here" is a claim to check, not a conclusion.** I shipped
    the social card in a fallback face saying the brand fonts could not be
    loaded. Satori cannot read WOFF2 and `public/fonts` held only WOFF2 — but the
    faces are SIL OFL and Google publishes TTFs. One `curl` fixed it.
17. **When a face changes, re-measure every clipped or `nowrap` box.** Share Tech
    Mono is wider than VT323, so the passport MRZ rendered 1043px into a 978px
    box and `overflow: hidden` clipped the tail — the part encoding the account
    number. Compute from the font's own advance metric.
18. **A `viewport: 0x0` reading means throw the measurement away, not adjust to
    it.** The browser pane collapses; when it does it reports the mobile layout
    at desktop width and every number is wrong.
19. **Calibrate from the distribution, not by eye.** Ruling 8 mapped `conf` onto
    0–99. "Map it to the full range" sounds obviously right and would have
    emptied the stylist — the composite only occupies 0.62–0.92 in practice.
    9,000 sampled looks put the floor at the 27th percentile instead.
20. **A revert-harness patch that hits a COMMENT copy of a string reads as a
    vacuous test.** One revert came back green because `.replace()` found the
    header comment quoting the very typo it was explaining. Re-anchor before
    believing "GREEN — VACUOUS".

## Traps learned in the morning round

1. **A skipped mutation is not a passing mutation.** A harness that reports SKIP
   on an anchor mismatch has tested nothing. Three of #230's fifteen skipped
   silently on leading whitespace.
2. **Measure the element you changed, not just the outcome.** `.cvhot` went
   354px → 292px while the document stayed 392px. Measuring only the document
   would have read as "the fix failed" and reverted a correct change.
3. **An automated `el.focus()` does not make an element match `:focus`** unless
   the browser window itself has focus. A probe reported "no change" and nearly
   read as a failed fix. **Click with the computer tool; do not call `.focus()`.**
4. **A suspiciously exact number is a lead, not a conclusion.** `380 + 12 = 392`
   looked decisive for the `/cover` reflow floor. `.adrawer` was not even in the
   DOM on that route.
5. **A source guard that reads comments is not a guard.** The first palette guard
   matched `getImageData(0, 0, 48, 48)` inside the comment *describing* the old
   bug. Strip comments before scanning source — this recurred three times.
6. **Test for label-wrapping before "fixing" unlabelled controls.** The first
   scan said 59; 16 were already correct via implicit `<label>` association. The
   real number was 43.
7. **`grep` exits 1 on no match**, which fails a `&&` chain and reads as the
   command before it failing. A passing test run was reported as a failing suite
   for exactly this reason.
8. **When converting a styled element to `<a>`, check whether its class already
   sets `color`.** `.brand2` declares `var(--grey)`, and an author rule already
   beats the UA anchor colour — adding `color: inherit` at higher specificity
   would have silently repainted the line.
9. **A token migration is not done until you grep for the OLD literal.** #218
   darkened `--red` to pass AA; `.skiplink:focus` kept the failing hex.
10. **`resize_window` preset "desktop" set the viewport to 0×0** here — blank
    screenshots, elements reported off-screen. Pass explicit width/height.
11. **Production cannot be read from a shell.** The Vercel bot checkpoint answers
    with a challenge page (200 *or* 429, with `x-vercel-mitigated: challenge`).
    **429 there is not an outage.** Confirm deploys via the GitHub deployments
    API, not curl. — **HALF WRONG, corrected in the evening: it blocks `curl`,
    not a real browser.** See §"Production is observable". The shell half stands;
    the conclusion that production was unobservable did not, and it cost weeks of
    treating the live site as a black box.
12. **A doc that hands its topic to a new doc must say so in the same PR.** I
    amended the 16 August handover through #232, then wrote to the claims
    register instead and left the handover telling readers to redo shipped work.
