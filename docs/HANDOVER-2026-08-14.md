- **TRAP (cost a red CI this session): every `supabase/schema-vN-*.sql` MUST end by inserting its version into `app_schema_migrations`** — a Postgres integration test asserts `max(version) == committedSchemaVersion()` (derived from the filename). v26's fix is the template.
