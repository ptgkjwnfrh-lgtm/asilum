## 🧠 What the measurement round found

**Two real defects, both live, neither visible from reading the code.**

**#333 — the novelty percentile was ranking over things no feed can serve.**
The popularity table also counts wire transmissions (`txn-…`) and every
probe row ever written. Against production: **53 of 968 counter rows moved
the exposure percentile of all 915 catalog items** (mean 0.0068, max 0.0132).
`assembleFeed` already declared the right law in a comment — *"a percentile
is a property of the POOL"* — and then handed the counter table over. Trap
34's exact shape. Fixed by FILTERING the counted rows, not replacing them:
ranking over the pool itself puts never-seen items into the distribution as
zeros, and midrank ties then place them at ~0.5 instead of the ~1.0 the
absent-value path gives — epsilon's pull toward the unseen, weakened.
`tests/distribution` caught that within one run.

**#339 — the core slate was paying for similarity nobody corroborated.**
`measure-vector-feed` had been FAILING at head in both worlds, in no
handover, because nothing runs it on a schedule. Vector neighbours ON cost
**0.0167 of top-24 affinity at paired sigma 0.0053** — three sigma of harm
to the slate almost every reader sees — and production ran that arm, because
the flag defaults on. The r26 resampled-sigma estimator is what exposed it;
under the old single-draw estimator it read as noise, so the feature was
shipped honestly against the instrument of its day.

**The fix that was refused, and why it matters.** Discounting uncorroborated
similarity inside `parts.gamma` dominated on every axis — and three tests
rejected it, correctly. A strong visual match with no edge scores
0.8 × 0.45 = **0.36** against one unverified person's click at
1/(1+2) = **0.333**, and that 0.027 is the documented rung stopping a forged
identity from outranking genuine similarity evidence. **The owner ruled
option 2** (`docs/vector-gamma-ruling-2026-08-21.md`, now headed RULED):
separate the two jobs. `parts.gamma` untouched — the ordering law holds,
`_parts` still explains the piece, attribution still names the bridge,
`_score` still reconciles with both — and only `byScore`, the core slate's
ranking key, discounts similarity that nothing corroborates. **Any** edge,
including a solo unverified one, restores full weight: the key never
punishes evidence, only its absence.

Result: flat GATE **FAIL → PASS**, top-24 **0.5226 → 0.5466**, reach
+0.0193, gamma-slot 0.4595 — the same numbers the rejected option bought,
with nothing spent.

**Two instruments repaired, which gate everything future.**

- **#338 replay got the noise floor its own header said it was owed.** The
  live Δ was tested against a resampled sigma while the replay Δ's sign was
  taken at face value, so a 0.0022 gap counted as a confident verdict. Now a
  pair is decided only when BOTH sides resolve it → flat and satiating both
  **CALIBRATED**. The amendment carries a **power criterion** (MIN_DECIDED=4
  of 10) precisely because a floor on both sides could otherwise pass by
  deciding nothing; seven pairs still decide. Mutation-proven: MIN_DECIDED=9
  prints `NO POWER` and flips both worlds red with every decided pair still
  agreeing.
- **`tests/distribution` was strengthened, at the owner's explicit word.** At
  12×2×3 the injected delta-×3 concentrator moved top-decile share **+0.0017**
  while the MUTANT arm — an *unmodified* split — moved it **0.0041**. The null
  was larger than the signal; both assertions had been riding luck. Raised to
  30×3×5 (~5:1 separation) and **verified passing at head**, so the size is
  tailored to neither arm. Its constants are now TWO: the carry test keeps
  its small world, because "a fresh world touches fewer items than a carried
  one" stops being provable once the pool saturates.

**One false lead, recorded so nobody re-treads it.** Search zero-results
looked like a live 9.8% cultural gap ("kurt colbain", "motley crue", "fight
club" returning nothing). They are **historical** — every one predates the
cultural read, and all ten sampled queries now return 48 results. Recent
30-day zero-rate is 2.2% and falling. No fix was shipped for a solved
problem; `asterisk.search-answer-rate` now guards the regression.

## ⚠ Traps learned 21 August

38. **A static `not-found` bakes the build-time path into anything that
    prints the route.** `/_not-found` landed in the shell's ROUTE readout and
    every real miss then hydrated under its own URL — React #418 on an
    otherwise clean console. `export const dynamic = "force-dynamic"` in
    `app/not-found.js` is the fix. `suppressHydrationWarning` would have
    FROZEN the wrong text.
39. **The a11y-label ratchet reads source statically and cannot follow
    `htmlFor` → `id`.** Pair `aria-labelledby` with the same label id.
40. **Vercel does not always fire the production build for a merge.** #331
    sat unbuilt 25+ minutes with previews building in 22 seconds. Fix:
    dashboard → Deployments → ⋯ → Create Deployment → pick `main` (the button
    flips to "Deploy to Production" once it resolves). **The dialog's spinner
    hung forever while the API call LANDED** — verify with
    `gh api commits/<sha>/status` (0 → 1 statuses) and `deploy:check`, never
    by clicking twice.
41. **`gh pr checks --watch` run immediately after `gh pr create` exits 1
    with "no checks reported".** Sleep ~20s first; nothing is red.
42. **The stored `gh` token has no `workflow` scope.** Any PR touching
    `.github/workflows/` is rejected at push. Write the YAML into `docs/` and
    hand it over.
43. **A test can pass on a margin smaller than its own null.** Before
    trusting any simulated comparison, measure the NULL arm at the same size.
    If the null moves further than the signal, the test is a coin flip
    wearing an assertion.
44. **Cheap noise floors: subtracting a per-arm CONSTANT cannot change a
    paired difference's variance.** `Var((X−c₁)−(Y−c₂)) = Var(X−Y)`. The
    first replay implementation computed the floor from per-session
    *adjusted* values — a full permutation battery per session — and had not
    finished when it was killed, for an identical answer.
45. **The pane's compositor serves stale frames after a hidden-pane resize.**
    Screenshots lie; `read_page` and DOM reads do not. Recover with an
    explicit `resize_window`, then navigate fresh.
46. **Michroma is a WIDE face.** Six caps overflow 375px below a ~40px
    floor — check mobile on any Michroma headline.
47. **`asilum-ui` rule 4 is real and was being skipped:** every shell-visible
    change must be checked in BOTH interfaces — MODULE RAIL and ORB HUB
    (`localStorage asilum-model` 01/02).
